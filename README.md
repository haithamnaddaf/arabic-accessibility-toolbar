# شريط تفضيلات الإتاحة للمواقع العربية — V5

مهارة عربية تساعد أدوات الذكاء الاصطناعي على إضافة شريط تفضيلات إتاحة إلى مشروع ويب وفق تقنيته الحالية، مع مرجع جاهز بـ**React + Tailwind** وواجهة RTL. يتيح الشريط تخصيص القراءة والمظهر والتنقل وحفظ الاختيارات محليًا.

**الأداة لا تجعل الموقع مطابقًا لـWCAG أو ADA، ولا تعالج بنية الموقع غير الميسّرة.** وضع ADHD هو دليل قراءة وتقليل حركة، وليس تدخلًا طبيًا. راجع [حدود الاستخدام](docs/KNOWN_LIMITATIONS.md) قبل دمجه أو وصفه للزوار.

## استخدمها مع الذكاء الاصطناعي

**المهارة لا تفرض React أو Tailwind.** تبدأ بفحص إطار المشروع ونظام CSS وطريقة العرض، ثم توجّه أداة الذكاء الاصطناعي لتكييف التنفيذ مع التقنية الموجودة. يمكن استخدامها كتعليمات لتكييف مشروع مختلف، لكن **التنفيذ المرجعي الوحيد المختبر حاليًا هو React V5**؛ لا توجد نسخ Vue أو Angular أو JavaScript مستقلة مختبرة ومرفقة.

- [اقرأ ملف SKILL.md داخل المستودع](accessibility-toolbar/SKILL.md).
- [نزّل المهارة كاملة مع أصولها ومراجعها المحلية — ZIP](downloads/accessibility-toolbar-v5.zip?raw=1).
- [خطة التكييف والقبول والاختبارات](accessibility-toolbar/references/framework-adaptation.md).

### تجربة سريعة

1. نزّل ZIP واستخرج مجلد `accessibility-toolbar`؛ احتفظ بـ`SKILL.md` و`assets` و`references` معًا.
2. أرفق المجلد أو أضفه إلى مساحة المشروع التي تقرؤها أداة الذكاء الاصطناعي. إذا كانت لا تدعم المجلدات، أرفق `SKILL.md` ومرجع التكييف والأصول التي تحتاجها بصورة منفصلة.
3. أرسل البرومبت التالي مع مشروعك. عند وجود آلية مهارات في أداتك، اتبع طريقة التثبيت الخاصة بها؛ الحزمة لا تدّعي استيرادًا تلقائيًا في كل أداة.

```text
استخدم المهارة المرفقة accessibility-toolbar لإضافة شريط تفضيلات إتاحة عربي إلى هذا المشروع.
اقرأ SKILL.md وreferences/framework-adaptation.md قبل التنفيذ.
افحص إطار المشروع ونظام CSS وطريقة العرض والاعتماديات الموجودة، واذكر ما وجدته.
كيّف التنفيذ مع التقنية الحالية؛ لا تضف React أو Tailwind إذا كان المشروع لا يستخدمهما.
استخدم أصول React V5 كمرجع للسلوك، ولا تعتبر نتائج اختبارها إثباتًا لنجاح التكييف الجديد.
حافظ على دعم لوحة المفاتيح والتركيز وعزل الحوار والتدفق والحفظ وتقليل الحركة وكتم الوسائط.
اجعل ADHD دليل قراءة وتقليل حركة دون ادعاء طبي، واجعل وظائف النطق غير المتاحة واضحة.
جهّز نسخة محلية واختبرها وفق خطة القبول، وسلّمني التغييرات والنتائج: نجاح وفشل وغير مختبر.
لا تنشر الموقع، ولا تصف الأداة أو الموقع بأنهما مطابقان بالكامل لـWCAG بناءً على هذه المهارة.
```

الحزمة تضم ملفات المهارة ومراجعها وأصولها المحلية، ولا تضم `node_modules` أو جميع مكتبات الأطر. اعتماديات React/ReactDOM وTailwind وLucide تخص اختيار المرجع React؛ للتكييف الآخر استخدم اعتماديات مشروعك وسجّل أي اعتماد جديد تحتاجه.

## الوظائف

| المجال | الوظائف |
| --- | --- |
| التنقل | فتح بـEnter وSpace والمؤشر؛ Escape للإغلاق؛ حصر Tab داخل الحوار؛ إعادة التركيز؛ السحب أو Alt + الأسهم |
| القراءة | حجم النص والتباعد والخط البديل، تمييز الروابط والعناوين، دليل القراءة وقناع القراءة |
| المظهر | تباين وداكن ورمادي وفلاتر تجريبية متبادلة الاستبعاد |
| النطق | قراءة الصفحة أو التحديد باستخدام Web Speech، إيقاف مؤقت ومتابعة وإيقاف وإعادة ضبط |
| تفضيلات أخرى | تقليل حركة CSS، إخفاء الصور، كتم الوسائط، تخصيص المؤشر والتركيز |
| الحفظ | localStorage على جهاز الزائر؛ لا خادم ولا تحليلات أو حساب مطلوب من المكوّن |

النطق يعتمد على الأصوات المتاحة في المتصفح والنظام؛ المكوّن لا يضمن أن خدمة النطق المحلية أو الشبكية للمتصفح تعمل بالطريقة نفسها على كل جهاز.

## مثال دمج المرجع المختبر: React

في مشروع React قائم:

```bash
npm install lucide-react
```

انسخ `accessibility-toolbar/assets/AccessibilityToolbar.tsx` و`accessibility.css` إلى مشروعك. أضف مسار TSX إلى قائمة `content` في Tailwind، وأضف ألوانه الدلالية كما في [دليل التركيب](docs/INSTALLATION.md).

```tsx
import { AccessibilityToolbar } from './components/AccessibilityToolbar';
import './styles/accessibility.css';

export function App() {
  return (
    <>
      <main>{/* محتوى موقعك بعناوين وتسميات وروابط ميسّرة */}</main>
      <AccessibilityToolbar />
    </>
  );
}
```

اعرض نسخة واحدة في التخطيط الجذري. في Next.js احتفظ بـ`"use client"` الموجود في المكوّن، وأضف CSS إلى ملف التنسيق العام أو التخطيط المناسب.

## وضع ADHD

1. افتح اللوحة واختر **دليل القراءة وتقليل الحركة (ADHD)**.
2. أغلق اللوحة لمعاينة الدليل.
3. حرّك المؤشر أو انتقل بـTab؛ يتبع الدليل موضع القراءة أو التركيز.

الإعداد يُحفَظ بعد إعادة التحميل. إعادة الضبط تلغيه. الاسم يصف أداة مساعدة اختيارية ولا يَعِد بنتيجة علاجية.

## استخدام المهارة في Codex

المجلد `accessibility-toolbar/` هو المهارة: `SKILL.md` مع الأصول والمراجع. نزّل ZIP، واستخرج هذا المجلد إلى مجلد المهارات الشخصي الذي يستخدمه إعداد Codex لديك، ثم استخدم `$accessibility-toolbar` مع مسار مشروعك. تعليمات دمج المكوّن والاختبارات محفوظة داخله. لا يُثبّت هذا المستودع المهارة تلقائيًا ولا يغيّر مشروعك دون تنفيذك تعليمات الدمج.

## نتيجة مراجعة V5

في المختبر المحلي المسجّل بتاريخ **14 أكتوبر 2026**: **35 حالة نجاح، 0 فشل مرصود، 4 غير مختبرة بالكامل**. نجحت حالات الفشل العشر التي ظهرت في V4 بعد إصلاحها، إضافة إلى 15 اختبار وحدة/تفاعل. راجع التقرير لمعرفة نطاق كل نتيجة؛ عدد الحالات ليس عدد معايير WCAG.

بقيت إعلانات قارئ الشاشة الحقيقي، والجودة السمعية للنطق، وتباين الموقع النهائي، وأجهزة اللمس والمتصفحات الأخرى غير مكتملة. صفر مخالفات مؤكدة في فحص axe المحدود **ليس شهادة مطابقة**.
