# نتائج الاختبار والحدود

هذا سجل المراجعة المحلية لـV4 → V5 بتاريخ 14 أكتوبر 2026، وليس ادعاء بإعادة اختبار على كل جهاز عند النشر. 36 حالة سابقة مع ثلاث إضافات: **35 نجاحًا، 0 فشل مرصود، 4 غير مكتملة**. حالات الفشل العشر السابقة نجحت ضمن المختبر. الاختبارات المرفقة: **15/15**.

بيئة المراجعة: macOS 26.6.2 arm64، Chrome 155.0.0.0، React 18.3.1، Tailwind 3.4.17، Vite 5.4.11، Vitest 2.1.8، TypeScript 5.7.2، jsdom 24.1.3، axe 4.10.2. عروض 320×700 و375×812 و1280×800، وتكبير Chrome الحقيقي 200% و400%، وصوت Majed ar-001.

- [التقرير الكامل: خطوات كل اختبار وأدلته](../accessibility-toolbar/references/validation-v5.html) — نزّل HTML وافتحه محليًا إذا عرض GitHub المصدر.
- [المقارنة بصيغة JSON](../accessibility-toolbar/references/validation-v5.json).
- [الأدلة المنقّحة](validation/evidence/).
- [حدود الاستخدام](KNOWN_LIMITATIONS.md).

ستة فحوص axe على النطاق المحلي أعادت صفر مخالفات مؤكدة، مع incomplete للمرجع aria-controls. لا يُساوي ذلك شهادة WCAG. عند فتح الحوار عُزلت خلفية الموقع بـinert؛ لا تشمل نتيجة الفحص كل الموقع في تلك الحالة.

## إعادة تشغيل الاختبارات المرفقة

```bash
npm ci
npm test
npm run typecheck
```

Vitest يختبر التطبيع والحدود والحفظ وعزل الحوار والتحديد والإيقاف وإعادة الضبط وADHD في jsdom. speech mock فيه محاكاة اختبار وحدة فقط. فحص TypeScript المحدد يشمل المكوّن ومثال الدمج، وليس جميع مشاريع المستهلكين.

إصدارات أدوات الاختبار مثبتة لتوضيح سياق المراجعة؛ لا يوجد خادم تطوير أو واجهة Vitest شبكية مفعّلة في أوامر المستودع. حدّث أدوات مشروعك وفق احتياجاته واختبر التغييرات قبل اعتمادها.

## اختبار الموقع الفعلي

اتبع خطوات التقرير لكل حالة، ثم أضف قارئ شاشة حقيقي وقياسات تباين للموقع وأجهزة لمس ومتصفحات مستهدفة. سجّل حالات نجاح وفشل وغير مختبر على حدة. لا تغيّر شفرة الحزمة لمجرد إنجاح fixture؛ سجّل الفشل أولًا ثم أصلح سببه بصورة قابلة للمراجعة.

السجلات التاريخية قد تضم محاولات استكشافية جرى تجاوزها. المعرّفات verified/final المشار إليها في التقرير هي المرجع. لا تعتمد tab-cycle.json القديم أو لقطات حالة صوت سريعة لتجاهل أحداث المحرك الأصلية. بعض قيم fixture-status تتأخر 300ms؛ هذه حدود القياس وليست دليلًا سمعيًا.
