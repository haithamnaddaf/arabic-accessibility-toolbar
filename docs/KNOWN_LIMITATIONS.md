# حدود الإصدار V5

هذه أداة تفضيلات للزائر. لا تجعل الموقع مطابقًا لمعيار أو التزام قانوني، ولا تصلح تلقائيًا التسميات وبنية العناوين والروابط والأخطاء والنصوص البديلة في الموقع.

## نطاق التقنيات

المهارة تبدأ بفحص التقنية وتوجيه التكييف معها، لكن الشفرة الجاهزة المختبرة هي React V5/Tailwind فقط. لم تُنتَج أو تُختبر في هذه الحزمة نسخ Vue أو Angular أو JavaScript مستقلة. أي تكييف جديد يتطلب خطة القبول ونتائج تخص مشروعه، ولا يرث نجاح المرجع.

## ما لم تكتمل مراجعته

| المجال | حالة المراجعة |
| --- | --- |
| قارئ شاشة حقيقي | محاولة الاتصال بواجهة VoiceOver انتهت بالمهلة؛ إعلانات الأسماء والقيم والتنقل في الخلفية غير متحققة. فحص AX/DOM ليس بديلًا. |
| الجودة السمعية | أحداث محرك Web Speech الأصلي للبدء/pause/resume/cancel نجحت؛ جودة نطق العربية أو أي تداخل مسموع لم يُحسم باختبار استماع مستقل. |
| التباين الشامل | عينات ألوان أدوات الحوار تحققت؛ جميع عناصر وألوان بكسلات الموقع النهائي بعد الفلاتر لم تُقَس. |
| الأجهزة والمتصفحات | المراجعة على Chrome/macOS؛ عرض الهاتف كان viewport، ولا اختبار لمس فعلي أو Safari/Firefox أو NVDA/JAWS/TalkBack. |

## حدود الدمج

- الفلاتر البصرية تجريبية ومتبادلة الاستبعاد. لا تصحح حالة طبية ولا تضمن التباين أو تمييز كل الألوان.
- portal يعزل أدوات الحوار عن فلاتر المحتوى. عناصر `fixed` الموجودة داخل جذور محتوى الموقع المفلترة قد تتأثر؛ افحصها في موقعك.
- خيار تقليل الحركة في الأداة يقلل CSS الحركات. تفضيل النظام `prefers-reduced-motion` يجعل تمرير القارئ فوريًا، لكنه لا يلغي تلقائيًا جميع حركات الموقع عندما خيار الأداة off؛ على الموقع احترام التفضيل بنفسه.
- وضع ADHD = دليل قراءة وتقليل حركة. لا يُدَّعى أثر علاجي أو نتيجة طبية. الدليل يُخفى أثناء فتح اللوحة؛ أغلقها لمعاينته.
- الخط البديل يستخدم fallback fonts، ولا يرفق خطًا متخصصًا للدسلكسيا أو ملف خط خارجيًا.
- توافر Web Speech والأصوات المحلية/الشبكية وجودتها يعتمد على المتصفح والنظام. هذا ليس بديلًا عن قارئ شاشة.
- لم تُراجع جميع إصدارات Tailwind/React أو أطر SSR أو سياسات CSP أو تبديل ثيم الموقع أثناء تشغيل الأداة.

## ماذا تعني نتائج الاختبارات؟

35 حالة ناجحة و0 فشل مرصود تخص المختبر المحدد. لا تعني أن كل وظائف الموقع أو معايير WCAG اختُبرت. فحص axe المحدود أعاد صفر مخالفات مؤكدة مع حالة `incomplete` تحتاج مراجعة يدوية. لا تستخدم عبارات «متوافق بالكامل» أو «يضمن الامتثال» بناءً عليه.

وصف مناسب: **شريط تفضيلات إتاحة بواجهة عربية، مع أدوات اختيارية لتخصيص القراءة والمظهر والتنقل**. اذكر حدود الدمج والاختبارات، واختبر الموقع الفعلي قبل إطلاقه.
